# Проверка JobPilot — 31.10.2026

Внесены исправления поиска, планировщика и отображения состояния. Локальная SQLite-база обновлена миграцией `0008_search_progress`.

## Исправленные проблемы

- Новый запуск очищает ошибки и время завершения прошлого запуска. Очередь, загрузка источников, оценка и завершение имеют отдельные статусы и журнал событий. Сетевые запросы не держат открытую транзакцию БД.
- Общие трёхчасовые интервалы используются локальным планировщиком, GitHub Actions и дополнительным Celery-обработчиком. Повторные ручные запросы защищены от постановки одного поиска в очередь дважды.
- Выдача нового запуска включает только публикации за текущий день по Москве. Неизвестные и будущие даты исключаются. Предыдущая выдача при сбое сохраняется с явной подписью.
- Поиск компаний в интерфейсе запускается фоном и восстанавливает видимое состояние после перезагрузки страницы. Добавлены мировой IT-каталог и 62 страны. Каталог подключает страницы вакансий, сохраняя отключённые пользователем источники.
- Карточка компании запускает поиск её вакансий по выбранному резюме. Официальные программы рекомендаций, каталожные компании и публичные профили имеют разные обозначения.
- Живой аудит выявил HTTP-ссылки CircleCI в Greenhouse. Для таких ссылок используется HTTPS-страница той же вакансии на официальном ATS.

## Границы проверки

PostgreSQL-интеграция пропущена: отдельный `TEST_POSTGRES_URL` не настроен. Облачная версия и фактические запуски GitHub Actions не обновлялись и не проверялись. Для них требуется публикация этих изменений; существующие переменные расписания и секреты должны оставаться настроенными. Локальное расписание работает при запущенном API. Remotive сохраняет установленный ранее шестичасовой кэш; остальные источники используют короткий общий кэш. Публичный профиль не подтверждает текущую работу человека или готовность дать реферал.
