# Личный помощник JobPilot

На телефоне откройте [страницу установки](https://jobs.blyadota.dev/android) и войдите обычным способом. Скачайте APK и установите его. Если Android запросит разрешение на установку из этого источника, оно понадобится браузеру для установки файла.

1. Откройте JobPilot и нажмите «Подключить через браузер». Сверьте 12 символов в приложении и на странице владельца. После подтверждения вернитесь в APK.
2. Передайте текст рекрутера через «Поделиться» или вставьте его в поле «Сообщение рекрутера». Для скриншота или аудио выберите файл, нажмите «Распознать» и проверьте текст.
3. Задайте язык и нажмите «Подготовить ответ». Сервер подберёт резюме и сохранит ответ в общей истории. Готовый текст можно изменить и скопировать. Пункт «Ответить с JobPilot» в меню выделенного текста также поддерживает возврат результата в редакторы, предоставляющие эту функцию.
4. В разделе «Панель» включите боковую вкладку. Android запросит доступ к показу поверх других окон. За положение вкладки отвечает перетаскивание. Для напоминаний о готовности разрешите уведомления. Android выбирает время фоновой проверки, история синхронизируется также при открытии приложения.

Чтобы ответить поверх переписки, откройте вкладку и нажмите «Снять экран». Подтвердите разовый захват в системном окне Android. Обведите текст, подвиньте рамку или потяните за угол. Кнопка «Выделить всё» выбирает весь кадр. Выбранная область отправляется на ваш VPS только по кнопке распознавания. Если браузер показывает пустой кадр, откройте обычную вкладку или используйте «Из файла» для уже сделанного системного скриншота. После проверки текста нажмите «Подготовить ответ», затем «Скопировать ответ».

Файл резюме сохраняется только по нажатию в выбранное пользователем место. Для отключения панели используйте экран «Панель» или действие в постоянном уведомлении. Отозвать доступ телефона можно на странице установки. Срок одной выдачи доступа составляет 90 дней.

## Сборка для владельца

Версия требует Android 8 или новее. Сборка использует JDK 17+, платформу Android SDK 35 и официальные Android Build Tools 35.0.0. Приложение использует платформенные API Android. Исполните в PowerShell из каталога проекта:

```powershell
./android/build.ps1 -Sdk $env:ANDROID_HOME -Jdk $env:JAVA_HOME
```

Подписанный APK записывается в `android/dist/jobpilot-assistant.apk`. Для публикации скопируйте его в `frontend/public/downloads/jobpilot-assistant.apk` перед сборкой веб-образа. Следующее обновление должно иметь больший `versionCode` и ту же подпись. На этой машине ключ хранится в `%LOCALAPPDATA%\\JobPilotSigning`; пароль к нему защищён Windows DPAPI текущего пользователя. Ключ подписи нужен владельцу для будущих обновлений.

Телефон генерирует свой случайный секрет и защищает его ключом Android Keystore. При подключении браузер передаёт владельцу отпечаток. Сервер проверяет действующий отпечаток при каждом обращении. Доступ устройства ограничен подготовкой ответа, общей историей, статусом, распознаванием и выбранным для черновика файлом. В APK нет серверного пароля или токена Telegram.
